Cara mencetak

Aplikasi ini mencetak lewat window.print() dan stylesheet @media print. Printer thermal harus sudah terpasang sebagai printer sistem pada Android, Windows, atau macOS.

  1. Pasang printer thermal 58 mm ke perangkat (USB, driver vendor, atau layanan cetak sistem).
  2. Di dialog cetak browser, pilih printer thermal tersebut.
  3. Ukuran kertas: 58 mm / 58mm x receipt / roll paper. Skala 100%. Margin None.
  4. Matikan header/footer browser (judul halaman dan URL).
  5. Jangan mengandalkan Web Bluetooth Classic SPP. Browser tidak menyediakan jalur itu.

ESC/POS tanpa dialog cetak memerlukan aplikasi pendamping atau local print bridge. Fitur itu berada di luar MVP web murni ini dan tidak disertakan.

Aplikasi statis offline-first. Tidak memakai server, database, framework, atau CDN.
